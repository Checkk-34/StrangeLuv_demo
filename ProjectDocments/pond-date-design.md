## 一、项目概述

一个纯 HTML/CSS/JS 单文件网页，为异地情侣提供 **随机周末安排 + 默契互动 + 留言** 的可爱工具。主题角色为 🐟小鱼（男生）和 🐸蛙蛙（女生），场景设定为春日小池塘。

---

## 二、技术决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 技术栈 | 纯 HTML/CSS/JS 单文件 | 零依赖、双击即用、易分享 |
| 数据存储 | localStorage（Supabase 预留） | 先快速 MVP，数据结构预留云同步接口 |
| 影视数据 | TMDb API (免费) | 自动获取近期热门影视，需注册 API Key |
| 图标方案 | SVG 手绘风格图标 | 匹配卡通主题，不用 emoji 作结构图标 |

## 三、视觉设计

### 3.1 配色方案 — 🌸 春日花池

| 变量名 | 色值 | 用途 |
|--------|------|------|
| `--bg-primary` | `#FFE4E1` → `#FFD1DC` | 全局背景渐变（樱花粉） |
| `--fish-orange` | `#FFAB76` | 🐟 小鱼（男生）操作色 |
| `--frog-green` | `#98D8A8` | 🐸 蛙蛙（女生）操作色 |
| `--card-cream` | `#FFF5E4` | 卡片/区块底色（奶黄） |
| `--text-main` | `#5D7A6E` | 主文字色（抹茶绿） |
| `--text-light` | `#8FA99A` | 次要文字 |
| `--white` | `#FFFAF5` | 气泡/弹幕底色 |
| `--heart` | `#FF8CA3` | 默契/爱心标记色 |

### 3.2 字体

| 用途 | 字体 | 来源 |
|------|------|------|
| 中文标题/正文 | Zen Maru Gothic | Google Fonts |
| 英文/数字 | M PLUS Rounded 1c | Google Fonts |
| 数字倒计时 | 等宽变体 (tabular-nums) | CSS font-variant |

### 3.3 设计风格

- **Claymorphism 轻量变体**: 圆角 16-24px、柔和内阴影、无硬边
- **角色驱动**: 所有交互用 🐟/🐸 头像标记操作者
- **手绘感装饰**: 虚线分隔、小水纹、荷叶点缀
- **触屏优先**: 最小触摸区域 44×44px，移动端适配

### 3.4 动效规范

| 元素 | 动画 | 时长 | 缓动 |
|------|------|------|------|
| 倒计时数字 | 每秒微弹跳 (scale 1→1.05→1) | 200ms | ease-out |
| 转盘 | 旋转 720°+ 随机停止 | 3-4s | cubic-bezier(0.25, 0.1, 0.1, 1) |
| 老虎机栏 | 三栏依次停止 | 每栏 1.5-2.5s | ease-out |
| 卡片 hover | translateY(-4px) + scale(1.02) | 200ms | ease-out |
| 删除项 | translateX(100%) + opacity→0 | 300ms | ease-in |
| 弹幕 | translateX 从右到左 | 8-15s (随机) | linear |
| 默契结果 | 依次弹出 + 轻微弹跳 | stagger 100ms | spring |

## 四、功能模块设计

### 4.1 顶部 —— 倒计时

```
┌──────────────────────────────────┐
│  距离今天结束还有  08:42:15      │
│  小鱼🐟 和 蛙蛙🐸 在等你        │
└──────────────────────────────────┘
```

- 实时更新每秒
- `24:00 - 当前时间` = 剩余时间
- 23:59:50 最后 10 秒有变色提醒
- 极小字号，不抢视觉重心

### 4.2 影视展示区

- TMDb API 拉取 "now playing" 或 "popular"
- 展示 5 张卡片：海报图 + 片名 + 年份/评分
- 横向滚动（移动端）或 flex 排列（桌面端）
- 卡片无复杂交互，纯展示，hover 浮起

### 4.3 随机玩法区（三合一 Tab 切换）

```
┌──────────┬──────────┬──────────────┐
│ 🎯 转盘  │ 🎰 老虎机 │ 💞 默契问卷  │  ← Tab 标签
├──────────┴──────────┴──────────────┤
│        [当前 Tab 内容区域]          │
└────────────────────────────────────┘
```

#### Tab 1: 🎯 转盘

- Canvas/SVG 绘制的圆形转盘，6-8 个扇形分区
- 每个分区 = 一个活动类型（电影/美食/户外/宅家/运动/约会）
- 点击「转动」按钮 → 旋转 + 指针停止 → 弹出结果
- 结果可「添加到清单」
- 小鱼按钮转动 → 橙色；蛙蛙按钮转动 → 绿色

#### Tab 2: 🎰 老虎机

- 三栏：时间（周六早/午/晚）+ 活动类型 + 具体活动名
- 点击「拉杆」→ 三栏依次滚动停止
- 结果可「添加到清单」

#### Tab 3: 💞 默契问卷

**流程:**

```
① [你 🐟] 从 8-10 个选项中勾选你想做的事
   → 提交 → 等待蛙蛙...
   
② [她 🐸] 同样的选项列表，勾选她想做的事
   → 提交 → 匹配中...

③ 双方都提交后 → ✨今日默契小事件✨
   展示交集项（两人都选了的事）
   → 可一键添加到清单，标记 💞 默契标签
```

- 选项预设（可后续自定义）:
  - 看电影 🎬
  - 吃火锅 🍲
  - 逛公园 🌳
  - 打游戏 🎮
  - 宅家刷剧 📺
  - 做手工 ✂️
  - 去图书馆 📚
  - 运动健身 🏃
  - 尝试新餐厅 🍽️
  - 视频聊天 💻

- 存储逻辑: 每人勾选结果存 localStorage，key 含日期
- 双方完成条件: 同一天内两人都已提交
- 如果只有一方提交：显示「等待对方中...」+ 可修改自己的选择

### 4.4 手动添加 & 活动清单

- 输入框 + 两个添加按钮（🐟添加 / 🐸添加）
- 清单项格式: `[角色图标] [活动名] · [时间段] [默契标记💞] [删除✕]`
- 删除有确认动画
- 数据存 localStorage，结构:

```js
activities: [
  {
    id: "uuid",
    text: "看电影",
    time: "周六下午",
    from: "fish",      // "fish" | "frog" | "match"
    date: "2025-03-15",
    matched: false
  }
]
```

### 4.5 弹幕留言板

- 留言以弹幕形式从右往左飘过
- 气泡样式: 圆角、角色色底（🐟橙 / 🐸绿）
- 右下角标注年月日（如 `2025-03-15`）
- 底部固定输入区: 输入框 + 发送按钮
- 新留言发送后立刻从右侧进入弹幕流
- 弹幕层级在最上方但不阻挡按钮操作
- 可暂停/恢复弹幕（hover 时暂停当前气泡）
- 数据存 localStorage:

```js
messages: [
  {
    id: "uuid",
    text: "周末快乐！",
    from: "frog",
    date: "2025-03-15T20:30:00"
  }
]
```
